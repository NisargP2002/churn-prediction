# Customer Churn Prediction

End-to-end ML system that predicts telecom customer churn with real-time 
explainability. Built with XGBoost, SHAP, FastAPI, and Streamlit.

## Results

| Metric | Score |
|--------|-------|
| AUC-ROC | 0.87 |
| Average Precision | 0.72 |
| Baseline (no model) | 0.735 |
